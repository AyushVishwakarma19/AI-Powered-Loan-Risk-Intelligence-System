# AI-Powered Loan Risk Intelligence System

An end-to-end machine learning and analytics platform designed to assess borrower risk, support lending decisions, and provide portfolio intelligence through predictive analytics, AI-generated insights, and interactive dashboards.

---

## Project Overview

This project combines Machine Learning, PostgreSQL, Flask, and Power BI to create a complete Loan Risk Intelligence System.

The platform enables users to:

- Predict borrower default risk in real time
- Classify applicants into Low, Medium, and High Risk categories
- Generate AI-assisted lending recommendations
- Monitor prediction history using PostgreSQL
- Explore portfolio insights through analytical dashboards
- Access all features through a responsive web application

---

## Project Highlights

### Risk Prediction Engine
- Logistic Regression model for borrower risk assessment
- Probability-based default prediction
- Automated risk scoring (0–1000 scale)
- Low, Medium, and High Risk classification

### AI Lending Intelligence
- AI-generated borrower explanations
- Risk factor interpretation
- Lending recommendations based on prediction outcomes

### Portfolio Analytics
- Executive Summary Dashboard
- Risk Analysis Dashboard
- AI Risk Intelligence Dashboard

### Data Management
- PostgreSQL database integration
- Historical prediction storage
- Prediction audit trail and record tracking
